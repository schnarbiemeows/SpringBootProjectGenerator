<h1 style="text-align:center;">Welcome to the <div style="color:blue">SpringBootProjectGenerator!</div></h1>

<p>This program will generate a series of templated SpringBoot microservices for you, based
off of a MySQL schema.</p><br/>
<p>The main class that kicks off the program is <b>SpringBootProjectGenerator.py</b></p>

<p><h2>Here is how it works:</h2></p>

<p><b>Basic premise:</b></p>

<p>The basic functionality that this program offers is to create some basic CRUD REST microservices for each of your tables. 
It can generate a seperate service for each table, 1 service for all of the tables, or you can use a file called 
<b>configuration/grouping.txt</b> to specify groupings of tables into services. Each service will also have <b>Junit</b> test cases
created within it, and will also generate json file that can be imported into <b>Postman</b> as a collection for testing as well.</p>

<p><b>A couple of assumptions:</b></p>
	<p>1. Only works with <b>MySQL</b> database at the moment, I use version 5.7</p>
	<p>2. Every table must have a primary key in it that is auto generated(auto_generated)</p>
	<p>3. Does not generate any foreign key functionality in the Java code</p>

<p><b>How to configure the program:</b></p>
<p>1. In a file called <b>configuration/SQL_file.sql</b>, you want to put in your MySQL definitions. These will be table creation statements.
There can be other stuff in there, but the program will only look for the words "create table" to figure out all of your tables.</p>
<p>2. in a file called <b>configuration/Configuration.py</b> : this file really just a configuration file. Here you will specify what you want the program to generate for you.</p>
<br/>
<br/>
<p><i>Some options currently available are:</i></p>
<br/>
<p><b>use_sonar_jacoco</b> : gives your program <b>sonarQube</b> analysis and <b>jacoco</b> code coverage functionality.<p>

<p><b>use_config_server</b> : if you know how to use Spring cloud configuration server, this will alter your services to use a config server</p>
					
<p><b>use_naming_server</b> : if you know how to use Spring cloud naming server, this will alter your services to use openFeign, Ribbon, and Eureka to use a Eureka naming server</p>
			
<p>more details can be found in this Configuration.py file</p>

<h1>Getting started:</h1></p>

<h2><b>set up your MySQL database :</b></h2>
<p><b>1.</b> setup a local MySQL instance</p>
<p><b>2.</b> create a simple table in this schema that has an autogenerated primary key</p>
<p><b>3.</b> paste the SQL DDL into SQL_file.sql</p>
<br/>
<h2><b>configure your application :</b></h2>
<p><b>4.</b> start by setting :</p>
					<p>use_sonar_jacoco = False</p>
					<p>use_config_server = False</p>
					<p>use_naming_server = False</p>

<p><b>5.</b> set lines 72 - 74 in Configuration.py to use your MySQL schema location, username, and password</p>
<p><b>6.</b> set lines 6 - 9 to whatever you want</p>
<p><b>7.</b> set generation_type = 1 on line 19. This is 1 service-per-table generation</p>
<p><b>8.</b> set beginning_port_num = whatever port number you want to use for this single service</p>
<p><b>9.</b> set destinationroot = where you want your Spring Boot project written to</p>
<br/>
<h2><b>run and launch the application :</b></h2>
<p><b>10.</b> run the application by right clicking on the SpringBootProjectGenerator.py class, and selecting run...</p>
<p><b>11.</b> in Eclipse, import the generated project as a maven project. Must have maven plugin for eclipse installed.</p>
<p><b>12.</b> run the mvn clean install targets to build the jar file</p>
<p><b>13.</b> right-click the project and runa s either a Java application or a Spring Boot app</p>
<p><b>14.</b> import the postman json clooection into postman. THis file can be found in the src/main/resources folder</p>
<p><b>15.</b> test the CRUD functionality using Postman</p>
